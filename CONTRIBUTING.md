# Contributing to FabricCraft

All contributions are welcome: documentation, tests, geometry algorithms, UI, material research and real-world sewing validation.

1. Discuss significant API, solver or dependency changes in an issue first.
2. Fork the repository, create a focused branch, and open a pull request referencing an issue.
3. Add tests, document numerical assumptions, units, tolerance choices, limitations and benchmark data.
4. Keep Rust code formatted with `cargo fmt` and linted with `cargo clippy`; run `cargo test`.
5. Do not add proprietary components or copy SolidCraft's restricted brand/interface assets. New dependencies require license and transitive-dependency review.
6. No generated or AI-assisted code should be merged without human review and applicable tests. Disclose substantial AI-generated contributions in PR descriptions.
7. Contributors retain copyright and agree their contributions are distributed under MIT OR Apache-2.0. No CLA is required initially; a Developer Certificate of Origin may be adopted after community discussion.

Follow the [Code of Conduct](CODE_OF_CONDUCT.md). For a suspected vulnerability, use the reporting instructions in the [security policy](SECURITY.md).
