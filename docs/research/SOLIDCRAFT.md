# SolidCraft and SolidCore reference-import audit

**Decision.** Keep SolidCore as an optional future CAD import adapter. The first product path accepts a mesh exported by the user's CAD application. FabricCraft uses the imported shape as a reference for fabric panels and patterns.

## Observed smoke test

An isolated Rust 1.100.0 Windows GNU executable decoded the pinned upstream fixture `crates/solidcore-tess/tests/data/box_2x3x4.json.gz`. The decompressed SHA-256 was `df28d22439753e9db1d88ef9f34e69aec203f56f8313b8c996d6ae370bb8704c`. With millimetres assumed for this fixture, chord tolerance 0.01 mm, and diagonal `√29` mm, the mesh produced **56 positions, 108 triangles, and six source face indices**. The measured area was **52.000000000000 mm²**, matching the analytic box area within the probe threshold of `1e-9 mm²`. The zero-tolerance request returned `TessError::Invalid`. The offline locked run exited 0. [Probe source and commands](probes/README.md)

This pin is a working reference for the tested mesh API. Its commit also documents 53 refuted upstream global point-solve answers. That limitation is outside the box probe and warrants care when considering other kernel APIs. Curved-face accuracy, real CAD exports, failure cases, stable provenance, and Linux and macOS portability remain to be tested. The mesh import path can proceed independently.
