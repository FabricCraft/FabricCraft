# Security policy

FabricCraft is pre-alpha and does not currently provide supported releases or security maintenance guarantees.

Send suspected vulnerabilities directly to the maintainers through the [private vulnerability report form](https://github.com/FabricCraft/FabricCraft/security/advisories/new). If you cannot access the form, open an issue asking for a private security contact. Share technical details only through the private channel.

Untrusted CAD and mesh files should be treated as hostile inputs. Importers must validate bounds, indices, sizes, recursion depth, and resource limits.
