# Security policy

FabricCraft is pre-alpha and does not currently provide supported releases or security maintenance guarantees.

Use **Report a vulnerability** on the GitHub repository’s security page when available. If that option is unavailable, open an issue asking for a private security contact. Share technical details only through the private channel. See [GitHub’s private reporting guide](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately).

Untrusted CAD and mesh files should be treated as hostile inputs. Importers must validate bounds, indices, sizes, recursion depth, and resource limits.
