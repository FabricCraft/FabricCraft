# Governance (initial)

FabricCraft is initially maintained by its founding maintainer. Decisions are discussed publicly in GitHub Issues or Discussions. Contributions are reviewed through pull requests; merge rights remain with maintainers. A maintainer may reject changes for correctness, licensing, safety, scope, or maintainability reasons and should explain significant decisions.

Large architecture changes require an issue or design proposal before implementation. Security disclosures should not include working exploits in public issues. The project may adopt a broader maintainer structure as contributors become established.

This governance document is a starting policy, open to community revision.
